# Hands on Epidemic diffusion

To start with this lab, I need you to have this repository on your laptop. 

You can clone or directly download it in a .zip.

Once you have it on your computer, I recommend you create a virtual environment, but as they are very common libraries, you can do:
```
pip install -r requirements.txt
```

If this does not work, install manually these packages: pandas, numpy, networkx, matplotlib using:
```
pip install 'package_name'
```
